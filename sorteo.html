Si a las 8:10 PM un equipo no se encuentra completo, el equipo contrario podrá solicitar que se declare No-Show (Forfeit del mapa al equipo incompleto).

01 // CREACIÓN DEL CANAL

Manager o Capitán

Cada organización designará a su Manager o Capitán para crear y nombrar un único canal oficial para su equipo.

02 // INTEGRANTES EN LLAMADA

Acceso Exclusivo

  • • 5 Jugadores Titulares
  • • Coach
  • • Head Coach (si cuentan con uno)
03 // CITA PREVIA

Desde las 7:45 PM

El Manager o Capitán deberá estar disponible desde las 7:45 PM (15 min antes) para crear y organizar el canal con tiempo.

IMPORTANTE: Una vez que los 5 jugadores y el staff se encuentren dentro de su canal, deberán permanecer ahí hasta que el encuentro haya finalizado.
